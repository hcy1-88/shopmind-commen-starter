# ShopMind Common Starter

ShopMind AI 电商微服务体系的统一基础框架，为所有业务服务提供标准化的底层能力和开发规范。

---

## 项目定位

Common Starter 是 ShopMind 业务层的「基础设施底座」，它不是业务代码的集合，而是**统一技术标准、统一开发规范、统一最佳实践**的承载者。业务方通过引入此框架，即可开箱即用地获得企业级应用所需的各种底层能力，无需重复造轮子。

## 核心能力

### 1. 统一异常处理

- **网关层异常统一拦截**：自动捕获并标准化网关层的各类异常，返回友好的错误响应
- **服务层异常统一拦截**：自动捕获 Servlet 层异常，统一异常码与错误信息格式
- **业务价值**：业务方无需关注异常处理细节，错误响应格式统一，前端对接更高效

### 2. 分布式追踪（TraceId）

- **请求链路追踪**：为每个请求自动生成全局唯一的 TraceId，贯穿整个调用链路
- **上下文透传**：TraceId 自动在服务间透传，支持跨服务问题排查
- **业务价值**：快速定位问题根源，排查效率显著提升

### 3. 认证授权

- **JWT 集成**：内置 JWT 解析与验证能力
- **自动认证拦截**：通过 `@RequireAuth` 注解即可开启接口鉴权
- **用户上下文**：自动提取用户信息并注入上下文，业务代码随时可取
- **业务价值**：简化权限开发，用户信息获取零成本

### 4. 统一结果封装

- **分页结果封装**：`PageResult` 提供标准的分页响应结构
- **结果上下文**：`ResultContext` 统一响应格式
- **业务价值**：接口响应格式标准化，前后端协作更顺畅

### 5. 分布式 ID 生成

- **雪花算法**：基于 Snowflake 的分布式 ID 生成器
- **全局唯一**：保证跨服务、跨实例的 ID 唯一性
- **业务价值**：无需担心 ID 冲突，分布式业务开发更从容

### 6. 统一存储服务

- **S3 兼容接口**：支持 S3 协议的对象存储
- **RustFS 集成**：默认集成高性能 Rust 文件存储
- **业务价值**：文件上传下载统一抽象，存储切换无感知

### 7. 中间件自动配置

- **Redis**：自动配置 Redisson 客户端
- **RocketMQ**：自动配置消息队列
- **Seata**：自动配置分布式事务
- **Nacos**：自动配置服务发现
- **业务价值**：减少配置代码，开箱即用

### 8. HTTP 客户端增强

- **请求拦截**：自动注入 TraceId 等上下文信息
- **响应拦截**：统一处理响应数据
- **业务价值**：服务间调用自动带上追踪信息，排查问题更便捷

### 9. 国际化支持

- **消息源助手**：`MessageSourceHelper` 提供便捷的多语言消息获取能力
- **业务价值**：轻松实现多语言支持

## 给业务方带来的价值

| 场景 | 不使用框架 | 使用 Common Starter |
|------|-----------|-------------------|
| 新建服务 | 需手动引入几十个依赖、配置各类中间件 | 引入 Starter，配置少量参数即可启动 |
| 接口鉴权 | 每个接口手动解析 Token、校验权限 | 加个 `@RequireAuth` 注解 |
| 获取用户信息 | 手动从请求中解析、注入到上下文 | 直接调用 `UserContext.userId()` |
| 问题排查 | 各服务日志独立，难以关联 | 通过 TraceId 精准定位问题链路 |
| 文件上传 | 需要自己对接存储 SDK | 调用 `StorageService.upload()` 即可 |
| 异常处理 | 手写 try-catch 或全局异常处理器 | 自动处理，统一格式 |
