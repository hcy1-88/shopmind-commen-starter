# Shopmind Common Starter

Shopmind AI 电商微服务项目的基础框架，基于 Spring Cloud Alibaba 2023.0.1.0 构建。

## 技术栈

- JDK 17
- Spring Boot 3.2.4
- Spring Cloud 2023.0.1
- Spring Cloud Alibaba 2023.0.1.0
